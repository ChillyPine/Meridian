<div align="center">

## 📖 About 📖

</div>
Meridian is a client side Minecraft mod for Hypixel Skyblock primarily focused on dungeon features with additional miscellaneous features for other aspects of Skyblock. Designed to assist in teaching dungeon floors, such as M7, to newer players while also adding many features to help veteran dungeon players.

## ⭐ Features ⭐

</div>

<details>
<summary><strong>General</strong></summary>

**Boxes**
- **Box Runic Mobs** — Boxes any mobs that are runic that you have line of sight to.
- **Box Rats** — Draws a box around rat mobs.
- **Box Matchos** — Draws a box around Matcho mobs.
- **Box Players (All Players, Specific Players)** — Draws an box around all players, or only players on a specified list.
- **Box Old Wolves** — Draws a box around Old Wolf mobs.
- **Box Femboys** — Draws a box around Femboy mobs.

**! Commands**
- **`!dt`** — Party command to add ASCII art DT in chat.
- **`!coords`** — Party command that prints your current coordinates.

**Chat Blockers**
- **Block "There are blocks in the way!"** — Hides this chat message.
- **Block "You earned # GEXP + # Event EXP from playing Skyblock!"** — Hides this chat message.
- **Block Profile ID Message** — Hides the profile ID chat message.
- **Block Profile Message** — Hides the profile-switch chat message.
- **Block Annoying HOTF Perk Disable Message** — Hides the recurring HOTF perk-disabled warning message.
- **Block Discord Warning Message** — Hides the Discord warning attached to messages.
- **Block Watchdog Message** — Hides Watchdog-related chat messages.
- **Block Radio Messages** — Hides messages related to the Blazetekk radio.
- **Block Beating Heart** — Hides beating heart messages in dungeons. 
- **Block Party Finder Warning Message** — Hides the party finder's warning message.
- **Block Blessing Messages** — Hides Blessing chat messages.
- **Block Superboom Pickup Message** — Hides the Superboom TNT pickup message.
- **Block Revive Stone Pickup Message** — Hides the Revive Stone pickup message.
- **Block Trap Damage Messages** — Hides trap damage chat messages.

**Party**
- **"Party List" Quick Actions** — Adds quick-action when running /pl (such as PV, Kick, etc)
- **Extra "Party List" Quick Actions** — Adds even more to Party List.

**Misc**
- **IRL Time** — Displays the real-world time on-screen.
- **Latest Version Sound List Button** — Adds a button to preview the sound list included in the latest version.
- **Check for Updates** — Checks whether a newer version of Meridian is available.
- **Download Latest Build** — Downloads the latest build of Meridian directly.
- **Inventory Search Bar** — Adds a search bar to containers. 

</details>

<details>
<summary><strong>Dungeons</strong></summary>

**Clear**
- **Box Star Mob** — Boxes star mobs in dungeons.
- **Box Fels** — Boxes stared Fels in dungeons.
- **Box Shadow Assassins** — Boxes all Shadow Assassins in dungeons
- **Box Bats** — Boxes bats in dungeons.
- **Bat Tracer** — Draws a tracer line to bats.
- **Locked Chest Notification** — On screen notification for locked chests.
- **Box Door Keys** — Boxes Wither / Blood keys.
- **Play Sound on Key Drop** — Plays a sound when a door key drops.
- **Quiz Progress HUD** — Displays live progress for the Quiz puzzle.
- **Quiz Countdown** — Millisecond-precision countdown timer for the Quiz puzzle.
- **Blood Open** — Notifies when the Blood Door / Blood Room opens.
- **Blood Full** — Notifies when the Blood Room reaches full mob count.
- **Blood Cleared** — Notifies when the Blood Room has been cleared.
- **Send Blood Progress in Party Chat** — Announces Blood Room clear progress in party chat.
- **Watcher Yap Hider** — Block the Watcher's dialogue messages.

**P1**
- **Holding Crystal** — On screen warning when holding a crystal in p1.
- **Healer Wish Notif** — Notifies when the Healer's Wish ability is ready or used.

**P2**
- **Box Storm** — Boxes Storms vaild hitbox.
- **PY Pad Helper** — Highlights the correct crush hight for PY.
- **High Crit Display** — Calculates high crit in storm for archer and displays it. 

**P3**
- **Simon Says Time & Party Notification** — Time SS, Send it in party chat.
- **Box Goldor** — Boxes Goldors vaild hitbox.
- **Healer Wish Notif** — Notifies when the Healer's Wish ability is ready or used.

**P4**
- **Highlight Platform Blocks to Mine** — Highlights the 3x3 to mine out for no platform drop in p4.

**P5**
- **Relic Helper** — Assists with locating and using the P5 relic.
- **Holding Relic** — On-screen warning when holding the relic in P5.
- **Arrow Stack Helper** — Helps track arrow stacking during P5.

**M3**
- **Fire Freeze Timer** — Displays a tick timer for Fire Freeze in F3/M3

**M5**
- **M5 Wish Reminder** — Reminds you to use Wish during the M5 floor.
- **Livid Health HUD** — Displays the correct Livid's health on a HUD.

**M6**
- **M6 Wish Reminder** — Reminds you to use Wish during the M6 floor.

**Misc**
- **Bottle Full Notification** — Notifies when your bottle is full.
- **Mask Used Notification** — Notifies when a masks / Pheonix has been used.
- **Instance Cooldown Timer** — Displays the cooldown before you can requeue a new dungeon instance.
- **Shitter List** — A custom list to track black listed players.
- **Auto Kick Shitter** — Automatically kicks black listed players from your party.
- **Announce Shitter w/ Custom Message** — Announces black listed players in party chat.
- **Send Shitter Reason Locally** — Shows the reason a player was flagged, displayed only to you.
- **Play Music at End** — Plays a random music disc on a run completion.
- **Short PF message** — Shortens the party finder messages.
- **Quick Party Actions** — Adds quick-access buttons for common party commands on player join.
- **Custom Leap Message** — Sends a custom message when using the Leaping.

<summary><strong>Carry Helper</strong></summary>
